# 한국민족문화대백과사전 이용 범위 문의 (초안, 2026-10-23)

안녕하세요. 토스 '앱인토스'에 올릴 운세 미니앱을 준비하고 있는 개인 개발자 [이름]입니다.

이용 안내(콘텐츠 이용)에 "한국학중앙연구원이 저작재산권 전부를 보유한 저작물은 저작권법 제24조의2에 따라 별도 허락 없이 자유이용이 가능하며, 범위는 항목 원고(본문) 전체"라고 되어 있는 것을 보고, 제가 계획한 이용 방식이 그 범위에 드는지 확인하고자 문의드립니다.

계획한 이용 방식은 다음과 같습니다.

1. 대상: 사주, 음양오행설, 띠(및 12띠 개별 항목), 궁합, 일진, 토정비결, 당사주, 삼재, 손, 택일, 윷점, 오행점 등 운세·세시풍속 관련 항목의 본문 텍스트
2. 방식: 본문을 저희 서버 데이터베이스에 저장해 두고, 사용자가 운세를 볼 때 AI가 문장을 작성하면서 참고하는 자료로 검색합니다(이른바 RAG). 사용자에게 보이는 것은 AI가 새로 쓴 운세 문장이며, 본문을 그대로 옮겨 보여 주지는 않습니다. 다만 본문 구절을 인용해 보여 줄 때는 "[항목명],『한국민족문화대백과사전』" 형식으로 출처를 표기하겠습니다.
3. 성격: 광고 수익이 있는 상업 서비스입니다. 본문을 재배포하거나 판매하지는 않습니다.
4. 수집: 대량 수집은 Open API 신청을 거쳐 API로만 하겠습니다.

여쭙고 싶은 것은 네 가지입니다.

- 위와 같은 상업 서비스 내 참고 자료 이용이 안내된 '자유이용' 범위에 포함되는지요.
- 항목 본문 텍스트가 공공누리 제1유형(출처 표시 조건, 상업적 이용 가능)에 해당하는 것으로 이해해도 되는지요. 안내 페이지에는 미디어 자료에만 유형 표시가 있어 여쭙습니다.
- Open API 인증키를 발급받아 확인해 보니 API 로는 약 15,800개 항목만 제공되고, 제가 쓰려는 항목들(사주 E0025957, 음양오행설 E0043032, 띠 E0017225, 궁합 E0006817, 일진 E0047325, 당사주 E0013895, 토정비결 E0059207, 삼재 E0026787, 택일 E0059132, 손 E0030463, 윷점 E0042795, 오행점 E0038604, 천기대요 E0055802, 세시풍속 E0029819)은 API 에서 조회되지 않았습니다. 이 항목들은 "한국학중앙연구원이 저작재산권 전부를 보유한 저작물"에 해당하지 않아 자유이용 대상이 아닌 것인지, 아니면 자유이용은 가능하되 API 제공 범위에만 들어 있지 않은 것인지요. 후자라면 본문을 받을 수 있는 방법이 있는지도 여쭙습니다.
- 출처 표기는 앱 안의 '참고 문헌' 화면에 이용한 항목명을 모아 표기하는 방식이면 충분한지, 아니면 결과 문장마다 표기해야 하는지요.
