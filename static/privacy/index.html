1. 수집하는 개인정보

오늘의 별자리 운세는 이름·연락처·계정 정보 같은 개인정보를 입력받지 않아요. 별자리를 찾을 때 넣는 생일과 태어난 해는 별자리를 계산하는 데만 쓰고 어디에도 저장하거나 보내지 않아요. 사용자가 등록한 별자리와 이름표(예: '나', '엄마'), 알림·광고 설정은 사용자 기기의 저장소에만 보관되고, 서비스 운영자에게 전송되지 않아요. 토스 앱에서 미니앱 데이터를 지우면 함께 지워져요.

2. 콘텐츠 받기

운세 문장과 오늘 하늘 표는 서비스 운영자가 GitHub Pages에 올려 둔 정적 파일에서 하루 한 번 받아요. 이때 개인을 알아볼 수 있는 값은 보내지 않아요.

3. 광고

서비스에는 앱인토스가 제공하는 광고(전면·보상형·배너)가 표시돼요. 광고 노출·성과 집계는 앱인토스 광고 정책에 따라 처리돼요.

4. 알림

사용자가 알림 받기에 동의한 경우에만 토스 앱을 통해 매일 아침 8시에 하루 1회 운세 알림을 보내요. 알림은 설정 화면과 토스 앱 알림 설정에서 언제든 끌 수 있어요.

5. 공유

'링크 공유'와 '카드 저장'을 누른 경우에만 토스 앱의 공유 기능으로 별자리 링크나 운세 카드 이미지를 만들어요. 카드 저장은 사진 접근 권한을 받은 뒤에만 기기 사진첩에 저장하고, 거부해도 다른 기능은 그대로 쓸 수 있어요. 링크에는 별자리 이름 외의 정보가 들어가지 않아요.

6. 분석

앱인토스 SDK 의 분석 기능으로 화면 진입·버튼 사용 같은 이용 통계를 기록해요. 별자리 이름 같은 값만 담고, 생일·이름표 등 개인을 알아볼 수 있는 값은 담지 않아요.
